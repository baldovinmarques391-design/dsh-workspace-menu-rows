# @local/dsh-workspace-menu-rows

工作区下拉菜单（Hero 的「桌面 ▾」）只显示 **4 行**，其余在菜单内部上下滚动；
「＋ 添加工作区…」作为菜单底部的固定行始终可见。

- 宿主侧（`index.js`）不注册任何东西。
- 浏览器侧（`client.js`）只在插件生命周期内挂一张样式表，并在每次菜单打开时
  测量一行菜单项的真实高度，把可滚动区域的上限设成 `4 × 行高`，所以缩放、
  主题、行距变化都不会错位；`:has()` 样式只是测量落地前的兜底。
- 只作用于「带固定底部行」的菜单卡片（工作区选择器是唯一会长到需要滚动的这种菜单），
  其他菜单不受影响。

调整行数：改 `client.js` 里的 `ROWS` 常量。
